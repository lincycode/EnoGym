# EnoGym 1.0.12

- 修复平掉此前成绩仍被标记为新纪录的问题；计时动作使用进阶后的目标，提前结束时保存实际用时。
- 训练方案支持重排并显示上次完成时间，分组列表可以滚动；修复体测提醒选择后未及时刷新的问题。
- 体测新增血压、备注、左右侧和腹围；营养记录可选开启铁和钾，并可打开分享的食物 JSON。
- Android 快捷设置可打开当天训练或会员卡。Wear OS 测试版可按需启用蓝牙同步，使用前需要授予权限。
- 修复键盘收起后残留空白、头像未及时刷新及部分设备启动卡住的问题。自托管增加多人独立数据和更多安装方式。

同步 GymMane 2.4.0 及手表安装脚本修复。可从「设置 → 关于 → 检查更新」下载安装，也可用下方 arm64 APK 覆盖安装。
