# EnoGym 1.0.13

- 同步 GymMane v2.5.0。同一动作可在方案里设置多个独立区块，交替组支持动作间休息，历史训练支持逐组查看。
- 动作和健康指标新增全屏趋势图，肌群训练量可按周或月设定目标，恢复估算考虑次数和相对负荷。
- 新增 Garmin FIT 导入和训练、饮食及综合报告，支持 PDF 和 Markdown。
- 饮食功能跟随原版更新，新增补剂连续记录、斋月模式和当天饮食文本复制。Android 可通过独立的 GymMane Scanner 扫码导入食品。
- 保留 EnoGym 的模板预览、周计划保护、鼠尾草白配色、肌群图颜色及组间无震动提醒。模板预览会显示结合当前训练场地选出的动作。

可从「设置 → 关于 → 检查更新」下载安装，也可使用下方 arm64 APK 覆盖安装。
