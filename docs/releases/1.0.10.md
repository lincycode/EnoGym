# EnoGym 1.0.10

- 训练中可逐组比较同一方案的上次用时。计时和有氧组可在达到目标后继续计数，成对哑铃可按单只录入、按两只计入训练量。
- 调整动作详情和选动作界面，新增动作，并在设置搜索中加入常见问题。
- 支持从 Liftosaur、JEFIT 和 StrongLifts 5×5 导入训练历史。CSV 可按日期和类别导出，空的训练方案分组会随备份保留。
- 可选用 NFC 贴纸打开当天的训练安排，默认关闭。支持更换桌面图标，默认仍是 EnoGym 的松绿跑者。
- 可补记或调整断食记录，也可粘贴 AI 生成的营养数据，核对后保存。

同步 GymMane 2.3.0 及之后的上游改动。已安装 1.0.8 或更高版本时，可在「设置 → 关于 → 检查更新」下载安装，也可用下方 arm64 APK 覆盖安装。
