# 训练休息超时与 RPE 预填验收

- 组间休息到点后，训练界面显示小浮云和累计超时时间。返回前台或重开训练草稿后，根据原截止时间继续计算。暂停训练会冻结读数。可点「结束休息」，开始计时组、完成下一组或结束训练也会收起提示。
- 启用 RPE 或 RIR 后，同一个动作区块里紧接在已评分正式组之后的正式组会显示预填值。确认完成时保存，可先修改或清空。第一组和热身组由用户填写。

Android 隔离模拟器用合成训练验证浅色卡片和 320 dp 宽的深色列表。实测完成第一组、从倒计时进入超时、切回前台、恢复草稿、关闭浮云，以及第二组预填和确认保存。卡片显示 RPE 8.5，列表换算为 RIR 1.5。截图位于本地 `artifacts/qa/2026-11-25/screens/`，运行日志位于 `artifacts/qa/2026-11-25-rest-effort/`。
